# Coda Pixel Studio download

[Download the standalone studio ZIP](https://github.com/cwoodmusic/testkitchen/raw/refs/heads/studio-downloads/downloads/coda-pixel-studio.zip)

Unzip the file. From inside the extracted `studio` folder, run:

```sh
python -m http.server 8000
```

Then open http://localhost:8000/ in your browser. You can also upload the studio folder to any static web host. No install, build, Firebase account, or game files are needed. Full instructions are included in the ZIP.

The app includes editable scenes/layers, pixel tools, collision painting and walk testing, asset placement, effects, photo conversion, native project backups, and complete integration bundle exports.
