How to play

Stack notes. Make rhythms.

Move and rotate each four-square shape. Every square has its own note or rest. Any connected sequence totaling four beats clears in a straight row or column. It can be part of a longer line, and the notes can come from the same piece.

Each four-beat run earns 200 points. Make more than one run in a single drop for a combo bonus: 100 points per additional run. Two runs earn 500 points; three earn 800. Eight beats can clear as two four-beat runs. Overlapping runs in the same row or column count once; crossing horizontal and vertical runs can form a combo.

Cleared spaces collapse. Chain reactions multiply the base run points, and additional runs in that same drop keep adding to the combo. Every 1,000 points raises the level and the falling speed. The game ends when the stack reaches the top.

A single eighth note and a pair of sixteenths each count as half a beat. Half notes and half rests count as two beats; dotted halves count as three. Rests count toward a pattern and sound as silence.

Controls: left/right or A/D to move, up or X to rotate clockwise, Z to rotate counterclockwise, down or S to lower, Space to drop, P or Escape to pause, R to restart. Use the buttons below the board on a touch screen.
